# Unsupervised Learning Customer Segmentation

## Repository Description

This project implements an unsupervised machine learning pipeline for customer segmentation using behavioral and transactional data. The objective is to identify distinct customer groups based on purchasing patterns, demographics, and spending behavior without predefined labels. By applying clustering techniques and dimensionality reduction methods, the project uncovers hidden customer segments that support targeted marketing, customer retention, and business decision-making.

The project follows a structured workflow that includes data preprocessing, exploratory data analysis, feature engineering, dimensionality reduction, clustering, cluster validation, and visualization. Advanced techniques such as Principal Component Analysis (PCA), the Elbow Method, and Silhouette Score analysis are used to determine optimal customer groups and improve segmentation quality.

### Key Objectives

* Understand customer behavior and purchasing patterns.
* Clean and preprocess customer datasets.
* Analyze customer characteristics through EDA.
* Engineer meaningful features for segmentation.
* Reduce dimensionality using PCA.
* Determine the optimal number of clusters.
* Apply clustering algorithms to discover customer segments.
* Visualize and interpret customer groups.
* Generate actionable business insights from segmentation results.
